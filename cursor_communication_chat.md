Самый быстрый способ в Cursor:

- Открой настройки: `Ctrl+,`
- В поиске введи `font`
- Основные пункты:
  - `Editor: Font Family` — шрифт кода (например: `JetBrains Mono, Fira Code, monospace`)
  - `Editor: Font Size` — размер
  - `Editor: Font Ligatures` — лигатуры (`true/false`)
  - `Terminal › Integrated: Font Family` и `...Font Size` — отдельно для терминала
  - `Workbench: Font Aliasing` — сглаживание шрифтов интерфейса

Если через JSON (точнее и удобнее), открой командную палитру `Ctrl+Shift+P` → `Preferences: Open User Settings (JSON)` и добавь:

```json
{
  "editor.fontFamily": "JetBrains Mono, Fira Code, monospace",
  "editor.fontSize": 15,
  "editor.fontLigatures": true,

  "terminal.integrated.fontFamily": "JetBrains Mono",
  "terminal.integrated.fontSize": 14
}
```

Если хочешь, подберу тебе готовый пресет “максимально читаемо для долгой работы” или “компактно и много кода на экране”.
