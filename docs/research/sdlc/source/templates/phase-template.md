# Implementation phase N —  schema

## Goal
One coherent observable behavior; explicitly state its dependencies.

## Context and references
Accepted design paths, code/contract citations, source commit.

## Files to create / modify
Exact paths only; 'unknown' requires research before code.

## Key decisions and invariants
Permitted dependency direction, security and failure behavior; no architecture decision by guess.

Small, dependency-ordered changes.

## Status and next phase
PASS/FAIL/UNKNOWN and exact commit; no checkbox-only completion.
